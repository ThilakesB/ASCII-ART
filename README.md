# ASCIIcam

This repository is configured to publish `index.html` to GitHub Pages using GitHub Actions.

## Publish

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push to `main` (or run the **Deploy static site to GitHub Pages** workflow manually).

After deployment, the site will be available at:

`https://thilakesb.github.io/ASCII-ART/`
